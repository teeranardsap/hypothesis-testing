การทดสอบสมมุติฐาน (Hypothesis Testing)

✨ สามารถพิมพ์กำหนดค่าตัวเลขต่างๆ ได้เองอย่างอิสระ

เครื่องมือตรวจสอบความจริงเชิงสถิติ: ใช้ข้อมูลตัวอย่างเพื่อตัดสินว่าความเชื่อเดิมนั้น "ยังเชื่อได้อยู่" หรือ "ต้องปฏิเสธ"

⚖️ 1. เราทำการทดสอบสมมุติฐาน "เพื่ออะไร"?

เปรียบเทียบง่ายที่สุดเหมือน "การไต่สวนในศาล":
  • สมมุติฐานหลัก (\(H_0\)): เปรียบเสมือน "ผู้ต้องหาบริสุทธิ์ไว้ก่อน" (สถานการณ์ปกติ ยังไม่มีอะไรเปลี่ยนแปลง)
  • สมมุติฐานทางเลือก (\(H_1\)): ข้อกล่าวหาที่ต้องการพิสูจน์ว่า "ผู้ต้องหาทำผิดจริง" (เกิดการเปลี่ยนแปลงแล้ว)
  • หลักการตัดสิน: เราจะยอมทิ้งความเชื่อเดิม (ปฏิเสธ \(H_0\)) ก็ต่อเมื่อ "มีหลักฐานจากตัวอย่างแน่นหนาจนแทบเป็นไปไม่ได้ที่จะเป็นเรื่องบังเอิญ"

🔍 2. Z-Test กับ t-Test ใช้ต่างกันอย่างไร? เมื่อไหร่ใช้อันไหน?

  • ใช้ Z-Test เมื่อ: เรารู้จักประชากรดีมาก คือ "ทราบค่าความแปรปรวนแท้จริง (\(\sigma\))" หรือมีกลุ่มตัวอย่างขนาดใหญ่มาก (\(n \ge 30\))
  • ใช้ t-Test เมื่อ: สถานการณ์จริงส่วนใหญ่ คือ "ไม่ทราบ \(\sigma\)" ต้องใช้ส่วนเบี่ยงเบนของตัวอย่าง (\(s\)) แทน และตัวอย่างมีขนาดเล็ก (\(n < 30\)) หางกราฟจะหนากว่าปกติเพื่อชดเชยความเสี่ยง (ใช้ค่า \(df = n - 1\))

📶 ตัวอย่างโจทย์จริง: การทดสอบความเร็วเน็ตหอพักนักศึกษา (พร้อมวิธีคิด)

สถานการณ์: หอพักโฆษณาว่าความเร็วเน็ตเฉลี่ยอยู่ที่ \(\mu = 50\) Mbps แต่นักศึกษาสงสัยว่าเร็วจริงตามอ้างหรือไม่ จึงสุ่มทดสอบความเร็ว \(n = 16\) ครั้ง พบความเร็วเฉลี่ย \(\bar{X} = 53\) Mbps และมีส่วนเบี่ยงเบนมาตรฐานตัวอย่าง \(s = 6\) Mbps ที่ระดับนัยสำคัญ \(\alpha = 0.05\) มีหลักฐานเพียงพอที่จะสรุปว่าเน็ตหอพักเร็วกว่า 50 Mbps หรือไม่?

📝 เฉลยขั้นตอนวิธีคิดอย่างละเอียด:
ขั้นที่ 1: ตั้งสมมุติฐาน
• \(H_0: \mu = 50\) (เน็ตมีความเร็วปกติ 50 Mbps)
• \(H_1: \mu > 50\) (เน็ตเร็วกว่า 50 Mbps จริง ทดสอบทางขวา)

ขั้นที่ 2: เลือกสถิติและคำนวณค่า
เนื่องจากไม่ทราบ \(\sigma\) ของทั้งหอพัก และ \(n = 16 < 30\) จึงใช้ \(t\)-test (\(df = 16 - 1 = 15\))
\[ t_{\text{cal}} = \frac{\bar{X} - \mu_0}{s / \sqrt{n}} = \frac{53 - 50}{6 / \sqrt{16}} = \frac{3}{1.5} = +2.00 \] ขั้นที่ 3: เปิดตารางหาค่าวิกฤตและตัดสินใจ
เปิดตาราง \(t\) ทางขวาที่ \(\alpha = 0.05, df = 15\) ได้ค่าวิกฤต \(t_{\text{crit}} = +1.753\)
เนื่องจาก \(t_{\text{cal}} = 2.00 > 1.753\) (สถิติคำนวณตกในเขตสีแดง)

💡 สรุปผล: ปฏิเสธ \(H_0\) ยอมรับว่าเน็ตหอพักมีความเร็วเฉลี่ยมากกว่า 50 Mbps จริงอย่างมีนัยสำคัญทางสถิติที่ 0.05
